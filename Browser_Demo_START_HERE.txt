Open `AiboOS/Web/index.html` on a modern desktop browser to explore the prototype. For correct offline storage, test with a local HTTP server rather than a file:// URL, for example: `cd AiboOS/Web && python3 -m http.server 8000` then visit http://127.0.0.1:8000. This browser server is for testing only; the iPhone application bundles the UI and does not require a cloud or external server.
